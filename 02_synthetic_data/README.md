# 02 — Synthetic Data

This directory preserves all supplied implementations of the Maya synthetic-data generator:

- `maya_synthetic_data_generator.ipynb`
- `maya_synthetic_data_generator.py`
- `maya_synthetic_data_generator.cs`

The Python rewrite preserves the original workflow/class coding while replacing Rhino/Grasshopper geometry types with NumPy-based equivalents.
